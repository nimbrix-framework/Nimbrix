# Package Overview (Package Map)

The following overview describes the most important directories and packages in the Nimbrix repository. It serves as a guide for developers who want to work with the project.

| Package/Folder                          | Contents & Purpose                                                                                                                                                                                                                                                                                  | Notes                                                                      |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| **src/Nimbrix/Nimbrix.CQRS**            | Core of the CQRS framework. Contains the abstractions for commands (`ICommand`), queries (`IQuery`), handlers and pipeline behaviors. The `ServiceResult` class standardizes success or failure of an operation; `ServiceResult<T>` extends this to include return types【463269862336282†L74-L113】. | Separating commands and queries makes the architecture more scalable.      |
| **src/Nimbrix/Nimbrix.AspDotNet**       | Integrates the CQRS framework into ASP.NET Core. `CqrsBaseController` provides methods for standardized HTTP responses such as `OkResponse`, `BadRequestResponse` and `CreatedResponse` and processes requests.                                                                                     | Provides base classes so controllers remain lean.                          |
| **src/Nimbrix/Nimbrix.Logging**         | Placeholder for logging infrastructure. This project currently defines only the project file and awaits implementation.                                                                                                                                                                             | Logging adapters (Serilog, OpenTelemetry) are planned for a later version. |
| **src/Nimbrix/Nimbrix.Persistence**     | Placeholder for the persistence layer. This is where data access will be encapsulated.                                                                                                                                                                                                              | Possible integration of Entity Framework, Dapper, etc.                     |
| **src/Nimbrix/Nimbrix.Samples**         | Sample applications, e.g. `WeatherForecastController`, showing how the CQRS and ASP.NET libraries work together.                                                                                                                                                                                    | Can serve as a blueprint for your own services.                            |
| **src/Nimbrix/Nimbrix.Testing**         | Infrastructure for test projects. Contains a project file but no implementation yet.                                                                                                                                                                                                                | Used to encapsulate unit and integration tests.                            |
| **src/Nimbrix.Angular/nimbrix-angular** | Angular workspace generated with the Angular CLI. Contains several libraries in `projects/`.                                                                                                                                                                                                        | Standard Angular structure configured via `angular.json`.                  |
| **…/projects/nimbrix-angular-core**     | Angular library for reusable core components and services. Build and publish scripts are described in the README.                                                                                                                                                                                   | Serves as the basis for other UI libraries.                                |
| **…/projects/nimbrix-angular-cqrs**     | Intended to provide interfaces to the .NET back end. At the moment only scaffold files exist.                                                                                                                                                                                                       | Will later contain HTTP clients and state management.                      |
| **…/projects/nimbrix-angular-ui**       | Package for UI components such as layout elements and controls.                                                                                                                                                                                                                                     | Currently unimplemented; adhere to the Angular Style Guide.                |
| **…/projects/nimbrix-angular-testing**  | Helper library for Angular unit tests.                                                                                                                                                                                                                                                              | Contains templates for tests (`.spec.ts`).                                 |

This map shows the modular structure of the Nimbrix framework: the back end is separated into clearly defined libraries, while the front end consists of several Angular packages. New functionality can be added via additional libraries without affecting existing components.
